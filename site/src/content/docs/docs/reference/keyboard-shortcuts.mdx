On a Mac, ⌘ is Command; elsewhere use Ctrl. Tool keys and single-key
shortcuts don't fire while you're typing in a field.

## Tools

| Key | Tool |
|---|---|
| V | Select |
| L | Line |
| R | Rectangle |
| C | Circle |
| P | Path |
| T | Text |
| D | Dimension |

## Files and output

| Key | Does |
|---|---|
| ⌘O | Open… |
| ⌘S | Save |
| ⇧⌘S | Save as… |
| ⌘P | Print / Export… |

These work from inside a field too: the field's value is applied first.

## Editing

| Key | Does |
|---|---|
| ⌘Z | Undo |
| ⇧⌘Z, or Ctrl+Y | Redo |
| ⌘A | Select every shape on a visible, unlocked layer (in a field, its text) |
| ⌘D | Duplicate the selection once, in the Duplicate card's direction and gap (unlinked) |
| Delete, Backspace | Delete the selection; or the selected path node or segment, dimension or radius label |
| Escape | Deselect and go back to the Select tool; first lets go of a selected path node or segment |
| Enter, F2 | Type into the selected text box |
| F | Fit the view to the drawing |

## While drawing and dragging

| Key | Does |
|---|---|
| Shift (dragging out a shape) | Square rectangle; line at multiples of 45° |
| Shift (releasing) | Stay in the same tool for another shape |
| Shift-click (Path tool) | Add a smooth node |
| Enter, Escape (Path tool) | Finish the path, open |
| Backspace, Delete (Path tool) | Take back the last node |
| Alt (dragging a path handle) | Break a smooth node into a corner |
| Alt-drag a corner node | Pull out a new handle |
| Shift (rotate handle) | Turn in 15° steps |
| Shift-click (Select tool) | Add to or take from the selection |
| Shift (lasso) | Add to the selection |
| Escape (lasso, placing or dragging a dimension) | Cancel |
| Space + drag, middle-button drag | Pan |

## Typing text on the drawing

| Key | Does |
|---|---|
| Enter | New line |
| Escape, ⌘Enter | Finish |

## In fields and dialogs

| Key | Does |
|---|---|
| Enter, Tab | Apply the value |
| Escape | Put back the value the field had |
| Escape (dialog or card) | Close it |

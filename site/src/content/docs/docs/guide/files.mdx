Delinya keeps your drawings in files on your own computer, never on a
server. A drawing is a `.dln` file (see the
[file format](/docs/reference/file-format/)).

## New, Open, Save

The first four toolbar buttons:

- **New** starts an empty, untitled drawing.
- **Open…** (⌘O) opens a `.dln` file and fits the view to it.
- **Save** (⌘S) saves the drawing. The first time, it asks where.
- **Save as…** (⇧⌘S) saves a copy under a new name.

<Screenshot src={toolbar} alt="The start of the toolbar: Delinya, then the New, Open, Save and Save as buttons" />

In Chrome, Edge and other Chromium browsers, Save writes straight back to
the file you opened or last saved. Other browsers can't do that, so Save
downloads the drawing to your downloads folder instead, and Open picks a
file to load.

## Unsaved changes

The file name at the right of the toolbar has a • after it while there are
unsaved changes. New and Open ask before throwing them away (offering to
save first), and the browser warns if you close the tab.

<Screenshot src={fileName} alt="The right-hand end of the toolbar: Untitled with an orange • for unsaved changes, and the drawing's title, Bookcase side, in quotes" />

## The drawing's properties

**Properties…** in the toolbar, or a click on the file name, opens the
drawing's properties:

- **Drawing**: title, author, revision and notes, printed in the title
  block. The title also shows beside the file name.
- **Grid**: the drawing's grid spacing, and your own Show grid and Snap to
  grid settings.
- **Variables**: the shared values that linked sizes use (see
  [Links](/docs/guide/links/)).
